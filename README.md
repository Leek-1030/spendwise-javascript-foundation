
# SpendWise - JavaScript Foundation

## Project Description

SpendWise is a simple budget management application built using HTML, CSS, and JavaScript.

The application allows users to enter their monthly budget and three expenses. It calculates total expenses and the remaining balance.

## Technologies Used

- HTML5
- CSS3
- JavaScript

## JavaScript Concepts Implemented

### 1. Variables

The application uses JavaScript variables declared with `let` to store the monthly budget and individual expenses.

### 2. Data Types

Number data types are used to store and process budgeting information.

### 3. User Input

The `prompt()` function collects the monthly budget and expense information from users.

The `Number()` function converts the entered values into numbers.

### 4. Budget Calculations

JavaScript performs addition to calculate total expenses and subtraction to determine the remaining balance.

### 5. Reusable Functions

The application uses reusable functions:

- `calculateTotalExpenses()` calculates all expenses.
- `calculateRemainingBalance()` calculates the remaining budget.
- `startBudget()` collects user input and displays the results.

### 6. Displaying Results

The `console.log()` function displays budgeting information and calculation results in the browser console.

### 7. Input Validation

The application uses `Number.isFinite()` to check whether entered values are valid numbers.

## How to Run the Project

1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in a web browser.
4. Click the Start Budget Calculation button.
5. Enter your monthly budget and three expenses.
6. Open the browser developer console using F12 to view the results.
